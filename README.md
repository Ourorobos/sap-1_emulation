# sap-1_emulation

This is a python project to practice writeing emulation software of computer hardware.
The hardware being emulated this project is the SAP-1 (Simple-as-possible) computer from Digital Computer Electronics 3rd edition by Albert Malvino and Jerald Brown

The SAP-1 is made of 11 modules.
1. Program Counter
2. Input and MAR (Memory address register)
3. RAM (You know what that is)
4. Instruction register
5. Controller/Sequencer
6. Bus
7. Accumulator (A register)
8. Adder/Subtractor (This is the ALU or Arithmatic Logic Unit)
9. B register
10. Output register (C register)
11. Binary Display
